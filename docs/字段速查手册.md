# GPU 硬件信息字段速查手册

> 本手册列出 `gpu-infra-probe` 采集/解析涉及的 20+ 核心字段，
> 便于阅读 `nvidia-smi -q` 输出与报告中的 JSON 时快速对照。

## 一、GPU 标识与型号

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `index` | GPU 在系统中的序号（0 开始） | `nvidia-smi --query-gpu=index` | `0` |
| `uuid` | GPU 全局唯一标识符 | `--query-gpu=uuid` | `GPU-xxxxxxxx-xxxx-...` |
| `name` / `Product Name` | GPU 产品型号 | `nvidia-smi -q` 的 `Product Name` | `NVIDIA A10` |
| `Driver Version` | NVIDIA 驱动版本 | `nvidia-smi -q` | `535.129.03` |
| `CUDA Version` | 驱动支持的 CUDA Runtime 最高版本 | `nvidia-smi -q` | `12.2` |

## 二、显存（FB Memory / BAR1）

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `memory.total` | GPU 显存总量 | `--query-gpu=memory.total` | `24576 MiB` |
| `memory.used` | 已用显存 | `--query-gpu=memory.used` | `512 MiB` |
| `memory.free` | 剩余可用显存 | `--query-gpu=memory.free` | `24064 MiB` |
| `FB Memory Usage` | 帧缓存显存使用明细（Total/Used/Free） | `nvidia-smi -q` | — |
| `BAR1 Memory Usage` | PCIe Base Address Register 1，CPU↔GPU 通信地址空间 | `nvidia-smi -q` | — |

> **FB vs BAR1**：FB Memory 就是常说的"显存"，存储 GPU 计算张量/纹理；BAR1 是 CPU 通过 PCIe 访问 GPU 显存的映射窗口。

## 三、PCIe 链路

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `PCIe Generation` | PCIe 代数（3.0/4.0/5.0），决定带宽上限 | `nvidia-smi -q` | `4` |
| `Link Width` | PCIe 通道数（x16/x8/x4），决定实际带宽 | `nvidia-smi -q` | `16x` |
| `Device Current PCIe Link Gen` | 当前实际协商到的 PCIe 代数 | `nvidia-smi -q` | `4` |
| `Device Current PCIe Link Width` | 当前实际协商到的通道数 | `nvidia-smi -q` | `16` |
| `Tx Throughput` / `Rx Throughput` | PCIe 双向瞬时带宽 | `nvidia-smi -q` | `5000 KB/s` |

## 四、性能与功耗状态

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `Performance State` (`P-State`) | 性能状态 P0(最高)-P12(最低) | `nvidia-smi -q` | `P0` |
| `GPU Current Temp` | GPU 核心当前温度（℃） | `nvidia-smi -q` | `45 C` |
| `Power Draw` | GPU 当前瞬时功耗（W） | `nvidia-smi -q` | `75.20 W` |
| `Power Limit` | TDP 上限（W），可由管理员设置 | `nvidia-smi -q` | `150.00 W` |
| `Clocks`（SM / Memory） | 当前 SM 与显存工作频率 | `nvidia-smi -q` | `1455 MHz` |

## 五、ECC 与可靠性

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `ECC Mode` | ECC 是否开启 `Enabled`/`Disabled` | `nvidia-smi -q -d ECC` | `Enabled` |
| `Volatile Uncorrectable` | 上电后单比特不可纠正错误数 | `nvidia-smi -q -d ECC` | `0` |
| `Aggregate Uncorrectable` | 历史累计不可纠正错误数 | `nvidia-smi -q -d ECC` | `0` |
| `Volatile Single Bit` | 上电后可纠正单比特错误数 | `nvidia-smi -q -d ECC` | `12` |

> ECC 错误数持续增长是显存故障的早期信号，巡检时重点关注 `Aggregate Uncorrectable`。

## 六、互联拓扑

| 字段 | 含义 | 数据来源 | 示例 |
|------|------|----------|------|
| `GPU0 ... GPUN` | 拓扑矩阵行/列头 | `nvidia-smi topo -m` | — |
| `NV#` | NVLink 互联 | `nvidia-smi topo -m` | `NV12` |
| `PIX` | 同 PCIe Bridge 下的互联 | `nvidia-smi topo -m` | `PIX` |
| `PXB` | 同 PCIe Switch 不同 Bridge | `nvidia-smi topo -m` | `PXB` |
| `SYS` | 跨 NUMA / CPU 互联 | `nvidia-smi topo -m` | `SYS` |
| `CPU Affinity` | GPU 对应的 CPU 逻辑核范围 | `nvidia-smi topo -m` | `0-7` |
| `NUMA Affinity` | GPU 所在 NUMA 节点 | `nvidia-smi topo -m` | `0` |

## 七、系统信息

| 字段 | 含义 | 数据来源 |
|------|------|----------|
| `uname -a` | 内核版本、机器架构、主机名 | `uname -a` |
| `/etc/os-release` | 发行版与版本号 | `cat /etc/os-release` |
| `dmidecode -t system` | 厂商、产品名、序列号、BIOS | `dmidecode -t system` |
| `lspci \| grep nvidia` | 系统 PCIe 上的 NVIDIA 设备列表 | `lspci` |

## 字段对照速查（与 JSON 中的 key）

| `nvidia-smi -q` 字段 | 解析后 JSON key（`gpu_detail.json`） |
|----------------------|----------------------------------------|
| `Driver Version` | `driver_version` |
| `CUDA Version` | `cuda_version` |
| `Product Name` | `product_name` |
| `Total`（FB Memory） | `fb_memory_usage.total` |
| `Used`（FB Memory） | `fb_memory_usage.used` |
| `Free`（FB Memory） | `fb_memory_usage.free` |
| `PCIe Generation` | `pcie_generation` |
| `Link Width` | `link_width` |
| `Performance State` | `performance_state` |

> 若字段为 `N/A`，通常是 vGPU 实例或 GPU 不支持该字段，正常情况。
