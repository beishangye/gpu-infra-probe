## 阶段1：采集层（Shell脚本基础）

**目标**：编写Shell脚本，自动采集所有硬件原始数据。

### 任务1.1：采集脚本骨架搭建

创建 `collect.sh`，实现以下功能：

```bash
#!/bin/bash
# gpu-infra-probe 采集脚本

OUTPUT_DIR="./data"
mkdir -p $OUTPUT_DIR
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")

# 1. 采集基础GPU信息
nvidia-smi --query-gpu=name,index,uuid,memory.total,driver_version --format=csv > $OUTPUT_DIR/gpu_basic_${TIMESTAMP}.csv

# 2. 采集详细硬件参数
nvidia-smi -q > $OUTPUT_DIR/gpu_detail_${TIMESTAMP}.txt

# 3. 采集拓扑信息
nvidia-smi topo -m > $OUTPUT_DIR/topology_${TIMESTAMP}.txt

# 4. 采集PCIe设备信息
lspci | grep -i nvidia > $OUTPUT_DIR/pci_devices_${TIMESTAMP}.txt

# 5. 采集系统信息
uname -a > $OUTPUT_DIR/system_info_${TIMESTAMP}.txt
cat /etc/os-release >> $OUTPUT_DIR/system_info_${TIMESTAMP}.txt

echo "采集完成，数据保存在 $OUTPUT_DIR/"
```

**验证标准**：执行 `./collect.sh`，检查 `data/` 目录下是否生成了5个文件。

## 阶段2：解析层（Python数据处理）

**目标**：用Python解析采集到的数据，输出结构化JSON。

### 任务2.1：解析CSV文件

创建 `parse_basic.py`：

```python
#!/usr/bin/env python3
import csv
import json
from pathlib import Path

def parse_gpu_basic(csv_path):
    """解析nvidia-smi --query-gpu输出的CSV文件"""
    with open(csv_path, 'r') as f:
        reader = csv.DictReader(f)
        gpus = list(reader)
    return gpus

def main():
    # 找到最新的CSV文件
    data_dir = Path("./data")
    csv_files = sorted(data_dir.glob("gpu_basic_*.csv"), reverse=True)
    if not csv_files:
        print("未找到CSV文件")
        return
    
    gpus = parse_gpu_basic(csv_files[0])
    
    # 输出JSON供后续使用
    with open("./data/gpu_info.json", 'w') as f:
        json.dump(gpus, f, indent=2)
    
    print(f"解析完成，共{len(gpus)}张GPU")
    for gpu in gpus:
        print(f"  - {gpu['name']}: {gpu['memory.total']}")

if __name__ == "__main__":
    main()
```

**验证标准**：执行后生成 `gpu_info.json`，里面的字段和 `nvidia-smi` 输出一致。

### 任务2.2：解析文本详情（关键！）

创建 `parse_detail.py`，解析 `gpu_detail_*.txt` 中的关键字段：

```python
#!/usr/bin/env python3
import re
import json
from pathlib import Path

def parse_detail(txt_path):
    """解析nvidia-smi -q输出的文本文件"""
    with open(txt_path, 'r') as f:
        content = f.read()
    
    # 提取关键字段
    driver_match = re.search(r'Driver Version\s*:\s*(.+)', content)
    cuda_match = re.search(r'CUDA Version\s*:\s*(.+)', content)
    
    # 提取GPU相关信息（第一个GPU）
    gpu_match = re.search(r'Product Name\s*:\s*(.+)', content)
    mem_match = re.search(r'Total\s*:\s*(.+)', content)
    
    info = {
        "driver_version": driver_match.group(1).strip() if driver_match else None,
        "cuda_version": cuda_match.group(1).strip() if cuda_match else None,
        "product_name": gpu_match.group(1).strip() if gpu_match else None,
        "memory_total": mem_match.group(1).strip() if mem_match else None,
    }
    return info

# main函数与前面类似
```

**扩展练习**：从 `nvidia-smi -q` 输出中提取出：
- PCIe链路速度（`PCIe Generation` + `Link Width`）
- 性能状态（`Performance State`）
- 显存使用率（`FB Memory Usage` 下的 `Used` / `Total`）

> 💡 **提示**：`nvidia-smi -q` 的输出是键值对格式，用正则表达式 `r'字段名\s*:\s*(.+)'` 就能匹配到。

### 任务2.3：解析拓扑信息

创建 `parse_topo.py`：

```python
#!/usr/bin/env python3
import re
from pathlib import Path

def parse_topo(txt_path):
    """解析nvidia-smi topo -m输出的拓扑矩阵"""
    with open(txt_path, 'r') as f:
        lines = f.readlines()
    
    # 找到矩阵开始的行
    start = 0
    for i, line in enumerate(lines):
        if line.strip().startswith('GPU0'):
            start = i
            break
    
    if start == 0:
        return None
    
    # 解析矩阵行（简化的解析）
    topo_data = []
    for line in lines[start:]:
        parts = line.strip().split()
        if parts and parts[0].startswith('GPU'):
            topo_data.append(parts)
    
    return topo_data

# 输出为JSON，供可视化使用
```

## 阶段4：健康检查模块

**目标**：检测异常指标，给出健康评分。

### 任务4.1：阈值定义

| 指标 | 正常范围 | 警告阈值 | 异常阈值 | 数据来源 |
|------|---------|---------|---------|----------|
| GPU温度 | 30-75°C | 75-82°C | >82°C | `nvidia-smi -q` 的 `GPU Current Temp` |
| 功耗 | <80% TDP | 80-90% TDP | >90% TDP | `Power Draw` / `Power Limit` |
| ECC错误计数 | 0 | >0 | 持续增长 | `ECC Errors` 部分 |
| 性能状态 | P0-P2 | P3-P5 | P6-P12 | `Performance State` |

### 任务4.2：检查函数实现

```python

    power = extract_value(detail_data, 'Power Draw')

        elif temp > 75:
            results.append({'level': 'warn', 'msg': f'温度偏高: {temp}°C'})
        else:
            results.append({'level': 'ok', 'msg': f'温度正常: {temp}°C'})
    
    # 性能状态检查
    if perf_state:
        if perf_state in ['P0', 'P1', 'P2']:
            results.append({'level': 'ok', 'msg': f'性能状态: {perf_state}（高性能）'})
        else:
            results.append({'level': 'warn', 'msg': f'性能状态: {perf_state}（非最高性能）'})
    
    return results
```

### 任务4.3：健康评分算法

```python
def calc_health_score(checks):
    """计算健康评分（0-100）"""
    score = 100
    for check in checks:
        if check['level'] == 'error':
            score -= 20
        elif check['level'] == 'warn':
            score -= 5
    return max(0, score)
```

## 📚 学习辅助资源

### 必读命令文档
1. `nvidia-smi --help-query-gpu`：查看所有可查询的GPU字段
2. `man nvidia-smi`：完整手册
3. `lspci -v`：查看PCIe设备详细信息

### 关键术语速查
| 术语 | 含义 | 数据来源 |
|------|------|----------|
| FB Memory | 帧缓存显存（GPU显存） | `nvidia-smi -q` |
| BAR1 Memory | PCIe Base Address Register 1，用于CPU-GPU通信的地址空间 | `nvidia-smi -q` |
| PCIe Generation | PCIe代数（3.0/4.0/5.0），影响带宽上限 | `nvidia-smi -q` |
| Link Width | PCIe通道数（x16/x8/x4），影响实际带宽 | `nvidia-smi -q` |
| ECC | Error Correcting Code，显存纠错 | `nvidia-smi -q -d ECC` |
| P-State | 性能状态（P0最高，P12最低） | `nvidia-smi -q` |
